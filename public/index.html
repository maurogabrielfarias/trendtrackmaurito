Ajustes y conexión con Claude

🔌 Vincular con Claude por MCP

Conecta TrendTrack a Claude como servidor MCP: Claude podrá rastrear tiendas, buscar productos y anuncios, ver alertas y guardar en tableros desde claude.ai, Claude Desktop, la app móvil o Claude Code, usando tu plan de Claude.

🔑 Claude dentro de la app (API key)

La pestaña Claude IA usa tu API key y se descuenta de los créditos de tu cuenta en platform.claude.com. Crea una key en Settings → API keys y guárdala como secreto de Cloudflare (nunca se guarda en la base de datos). Internamente, Claude usa las mismas herramientas del servidor MCP + búsqueda web.
